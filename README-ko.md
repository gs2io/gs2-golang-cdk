# gs2-golang-cdk

Game Server Services(https://gs2.io)의 GS2-Deploy 템플릿을 Go로 생성하기 위한 CDK입니다.

## Game Server Services란

Game Server Services(GS2)는 게임 개발에 특화된 백엔드 서버 서비스(BaaS)입니다.

GS2는 게임 개발의 효율을 높이기 위해 탄생한 범용 게임 서버 솔루션으로, Games as a Service(GaaS)와 Live Gaming 등을 지원합니다.

이 서비스를 통해 플레이어 데이터를 유연하게 관리하고 분석할 수 있으며, 게임 내 자원의 유통과 소비량을 적절히 분석하여 건전한 게임 환경을 유지할 수 있습니다.
또한 스토리 진행 관리와 소지품 관리 등의 기능을 제공하여 게임의 수익화와 플레이어 참여도 향상에 기여합니다.
GS2는 온라인 기능을 지원하며, 게임 개발자가 데이터 분석과 게임 내 경제 관리를 쉽게 수행할 수 있도록 도와 게임의 성공에 기여합니다.

## 시작하기

SDK를 이용하려면 GS2 자격 증명이 필요합니다.
[GS2 설정](https://docs.gs2.io/ko/get_start/tutorial/setup_gs2/)의 절차에 따라 자격 증명을 발급해 주세요.

- Go 1.18+
